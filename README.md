# 🚖 Uber Ride Data Analytics & EDA

Exploratory Data Analysis (EDA) and pattern discovery on Uber ride datasets using Python, Pandas, and Seaborn.

## 📌 Project Overview
This project analyzes ride-hailing patterns, booking trends, trip durations, mileage distributions, and customer trip purposes (Business vs. Personal) to derive operational insights.

### Key Analysis Highlights
- **Temporal Patterns:** Peak booking hours, day-of-week trends, and monthly demand seasonality.
- **Trip Segmentation:** Breakdown of trips by purpose (Meeting, Meal/Entertain, Customer Visit, Errands, Commute).
- **Distance & Duration Metrics:** Mileage distribution analysis and outlier detection.
- **Geographic Hotspots:** Most frequent starting and stopping locations for ride pickups and drop-offs.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook

## 🚀 How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/Haricharanv/UberDataAnalysis.git
   cd UberDataAnalysis
   ```
2. Install required dependencies:
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook Uber_data_analytics.ipynb
   ```
